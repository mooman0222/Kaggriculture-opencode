$ARGUMENTS の内容を `.opencode/knowledge/` の該当ファイルに記録してください。

- **検証済みの結果** → `findings.md` (テーブル形式: 日付・知見・検証方法・条件・根拠)
- **未検証のアイデア** → `hypotheses.md` (優先度つき)
- **実験の記録** → `experiments.md` (次の ID を採番して追記)
- **コンペの状況・スコアリング変更** → `meta.md`

記録時は「いつ・どんな条件で・どう検証したか」を必ず含めること。
条件なしの知見はナレッジとして価値がない (README.md のルール参照)。
既存の記述と矛盾する結果が出た場合は、追記ではなく上書き + 変更履歴に追記する。
