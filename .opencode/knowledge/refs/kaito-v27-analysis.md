## 戦略 (シミュレーション検証済み)

- 動物 **9 COW + 4 SHEEP** (牧場13) + メロン(バースト売り) + イチゴ(終盤エンジン) + 小麦(投げ売り)
- 土地: NE ($1k, day6) + SW ($2k, day10)。**SE は買わない**
- ハンド: 全30日雇用、計262人日・総額 $7,148。中盤以降は 6〜14人/日
- SELL 168件: 小麦455 / イチゴ286 / 肥料235 / ミルク241 / メロン114 / 羊毛132

## 私たちへの示唆 (重要度順)

1. **動物 + 肥料売り (最大の構造差)**: 9COW+4SHEEP でミルク+羊毛+肥料の三重収入。
   **肥料は動物1頭/日で無料生成 → 13頭 = 1日13個 ≈ $1,300/日 (base)**。小麦フィード負担を
   差し引いても大幅プラス。私たちは肥料収入を完全に見落としている
2. **メロンの売り方が逆**: 私たちは常時10個ずつ分割売却 (価格を恒常的に押し下げる)。
   Kaito は **バースト売り** (day10: 30個 / day20: 60個) で価格窓を狙う。SELL_CHUNK=10 は再検討余地
3. **終盤の小麦投げ売り**: 小麦は log 曲線で glut 吸収 → 165個一括売却でも価格がほぼ落ちない。
   私たちの終盤換金を小麦でより積極的にできる
4. **イチゴが終盤エンジン**: 継続作物 (2日ごと4回)。day10 以降 10〜38個/日の定常売却。
   メロン (1回限り) より終盤の現金化に強い
5. **土地は「何を植えるか」次第**: 追加2区画を価格吸収型の小麦/イチゴに使えば $3,000 投資を回収。
   多品種化すれば USE_LAND の再評価余地あり
6. **労働力投入量**: 中盤以降 6〜14人/日 ($7,148)。私たちの HIRE_MAX=2 は収入の天井要因かも
7. **売却順序最適化** (`_rank_sell_slots`): 価格影響の大きい売りを先に並べる小改善 (+$1k前後)。
   小麦+メロンの複数売却を持つ私たちに即適用可能
8. **価格予測関数** (`_market_price`): 公式価格関数の完全再実装 (定数テーブル + 曲線形状)。
   売却判断を「現在価格+売却後予想価格」ベースに高度化できる
