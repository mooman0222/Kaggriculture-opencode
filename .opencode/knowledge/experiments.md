## 再現方法メモ

- リアクティブ型時代 (E001-E017b): `main.py` のモジュール定数 (`USE_LAND`, `USE_HANDS`,
  `HIRE_MAX`, ...) をテスト前に書き換えて `evaluate.py` を実行する方式
- ルート型 (E018 以降): `agents/adaptive_route.py` の定数 (`GAP_HIRE_MAX`, `M5_*` など) を
  書き換え、`tests/eval_routes.py` / `tests/evaluate.py` で評価
  (vs base / seeds 0-14 必須 — seeds 100-104 は不利なシード帯、E018-M4a)
- **A/B の罠 (E018-M5b で踏んだ)**: `make_adaptive_agent` 実行後にモジュール定数を書き換えると、
  呼び出し時に定数を参照する部分 (GAP_HIRE_MAX, M5_OFFSET 等) の挙動まで変わって A/B が汚染される。
  **フラグは `build_plan` 時に plan へコピーされ、以後 plan を参照する** (現行実装はこの方式)。
  正しい A/B: フラグ設定 → agent 生成 → 評価、をエージェントごとに順に行う
