## 6. 生きている問い

1. **自前の層を持つ相手に勝てない**。実戦 120 戦の分解: v43 型開幕の相手 61 局 67%/+1,028、**v46 素 31 局 58%/+399**、
   **v46 + 自前の層 23 局 22%/−1,710**。唯一の負け筋がここ。相手の層は (a) 売りの**時刻を組み替える** (同じ品目を消しては足す)、
   (b) **h0-2 と h21-23** に集中、(c) 76% でスロット 0 に SELL、(d) ユニット行動も 16.3% の step で変える。
   夜明けガードは (b) の入口を押さえたが、(a)(d) は未着手。
2. **エンジン規則の残りの穴を探す**。`refs/engine_facts.md` と `third_party/kaggriculture-cppsim/sim/sim.hpp` を突き合わせる。
   夜明けガードは `drop_inventories` から見つけた。同種の規則がまだあるはず。
3. ~~E081 の実戦結果が「帯の席差し替え + 反応する直接対戦」を裏づけるか~~ (09-28 決着): 09-26 までは裏づけた (E081 2484 対 E079 2200) が、
   09-26 夜からの母集団では逆転 (5 節)。**判定用の帯は日ごとに取り直す**しかない。母集団の入れ替わりは `rating_traj.py` の相手提出 ID 帯別勝率で最初に見える。
4. ~~早売りを相手の型で切り替える~~ (09-27 に試作・棄却): E083 として実装 (既定=E082ペース、窓頭で相手の積み増し SELL ≧自uncapped+10 を2回検知したらラッチでダンプ)。検証で検知が一度も発火せず E082と完全一致 (対E081 6W18L −266・対e072 22W2L +748とも同値、dump_games=0)。理由: ダンプ鏡像は同農場→同棚→同量ダンプで「積み増し」が恒等的に0になる。−266は同着順の同手番レース (slot順) の問題で量検知では捉えられない。類似度検知への作り替えは、誤発火で+190/+84を消す側のリスクが大きく見送り。−266は兄弟戦のみの稀事として受容。コードは除去 (x082に実験モードは残置)。
