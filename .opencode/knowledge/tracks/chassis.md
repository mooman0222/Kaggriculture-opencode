## 3. 測り方

| 目的 | コマンド |
|---|---|
| 自分の土台に対する上乗せ | `tests/kag_eval.py agents/X/main.py --vs third_party/public_agents/<土台>/main.py --games 32` |
| 現提出との比較 | `--vs agents/<現提出>/main.py --games 32` |
| **実戦席差し替え (最も当てになる)** | `--replays 'tmp/<battles>/episode-*.json' --team MMN0222 --base agents/<現提出>/main.py` |
| 世界を固定 | `--shops <8 店をカンマ区切り>` |
| 実戦の取得 | `kaggle competitions episodes <ref>` → `xargs kaggle competitions replay` → `tests/fetch_battles.py` / `tests/rating_traj.py <ref>` |

- **ユニット行動を触らない層なら分散が小さく微差が測れる** (クローンが保たれるため)。触ると位置がドリフトして分散が跳ねる。
- **世界ドロー (09-23)**: 農場行動を 1 手変えるだけでショップ列が入れ替わる (±30-50k)。**農場を触る変更は pinned shops で測る** (`kagsim.Game(seed,720,[8 shops])`)。
- **ルート表の掃引手順 (E074 で確立)**: 1 世界で全 40 ルートをスクリーニング → 上位 2 を **held-out 5 世界 × 4 相手 × 両席 = 40 ペア戦**で確認。
  採用条件は delta > +500 かつ wins ≥ 24/40。1 世界だけの大勝は必ず捨てる (winner's curse を 3 回踏んだ)。
- **同 seed・同席のペア差**を取る。夜明けガードは +248±24 (t=10.3) で検出できた。
- **seed 範囲で結果が変わる**: 同じ E066 vs v46 が seed 0-15 で +102、seed 7000-7039 で +366。狭い範囲で結論を出さない。

   (b) **h0-2 と h21-23** に集中、(c) 76% でスロット 0 に SELL、(d) ユニット行動も 16.3% の step で変える。
   夜明けガードは (b) の入口を押さえたが、(a)(d) は未着手。

   夜明けガードは `drop_inventories` から見つけた。同種の規則がまだあるはず。
