# 公開シャシー + ライブ層 — 現在地 2026-09-25 / 状態: **本線 (提出系)**

公開ノートブックの生産ライブラリ (テープ + 反応層) を土台にし、その上に自前の市場層を重ねる路線。
すべての提出はこの路線。市場処理の内部は `refs/chassis_market_anatomy.md`、版の載せ替えは `refs/chassis_upgrade_playbook.md`。
**世界 (ショップ列) は両者の盤面が決める** ため、農場行動を触る実験は pinned shops 必須 (`refs/world_draw.md`)。

**この路線は「共有市場の取り分」の勝負である。** 牛乳・羊毛は両者の供給が需要を超えて飽和しており、増産は損 (E075)。
卵・小麦は対数曲線で飽和せず、トマトは誰も売らなければ $300 まで上がる。鏡像戦は既定のままなら引き分けで、
**鏡像と違うルート (ガチョウの多い r112/r120/r110/r103) を選ぶ**か、**鏡像より先に売る**ことで勝ちが決まる。
エンジンはユニット行動 → 市場の順に処理するので、**その手番に倉庫へ置いた品は同じ手番に売れる** (`sim.hpp` step)。
先に売る競争の下限はここで、観測時点の倉庫だけを見る前倒し (EXP179 の 4 手、E076 の窓先回し) はここに届かない。

- **ユニット行動を触らない層なら分散が小さく微差が測れる** (クローンが保たれるため)。触ると位置がドリフトして分散が跳ねる。

  採用条件は delta > +500 かつ wins ≥ 24/40。1 世界だけの大勝は必ず捨てる (winner's curse を 3 回踏んだ)。
- **同 seed・同席のペア差**を取る。夜明けガードは +248±24 (t=10.3) で検出できた。
- **seed 範囲で結果が変わる**: 同じ E066 vs v46 が seed 0-15 で +102、seed 7000-7039 で +366。狭い範囲で結論を出さない。

## 6. 生きている問い

1. **自前の層を持つ相手に勝てない**。実戦 120 戦の分解: v43 型開幕の相手 61 局 67%/+1,028、**v46 素 31 局 58%/+399**、
   **v46 + 自前の層 23 局 22%/−1,710**。唯一の負け筋がここ。相手の層は (a) 売りの**時刻を組み替える** (同じ品目を消しては足す)、
   (b) **h0-2 と h21-23** に集中、(c) 76% でスロット 0 に SELL、(d) ユニット行動も 16.3% の step で変える。
   夜明けガードは (b) の入口を押さえたが、(a)(d) は未着手。
2. **エンジン規則の残りの穴を探す**。`refs/engine_facts.md` と `third_party/kaggriculture-cppsim/sim/sim.hpp` を突き合わせる。
   夜明けガードは `drop_inventories` から見つけた。同種の規則がまだあるはず。
3. **E081 の実戦結果が「帯の席差し替え + 反応する直接対戦」を裏づけるか** (09-25)。予測は帯で勝率 39〜43% → 54〜75%。
   同じ時間帯に E079 を対照として再提出して比べる。外れたら席差し替えは早売り型の相手にも楽観 (相手の反応が抜ける) と読む。
4. **早売りを相手の型で切り替える**。E081 (win) でも herd 系そのまま (テープどおりに売る鏡像) には −700。
   相手の売りは共有市場の在庫差分から推定できる (x078 AFR の推定部)。テープの予定手番で売る鏡像を見分けたら E076 の窓先回しに戻す。
5. **売り注文を出しすぎている疑い (未確定)**。1 局の SELL 注文数は **我々 500 / 1 位 267 / 2 位 397**、羊毛の発注個数は
   **我々 827 / 1 位 188 / 2 位 165**。ただし発注 ≠ 約定で、価格側の差は小さい (羊毛が $5 以下の時間 20.6% 対 17.6%)。
   kagsim テレメトリは合計のみ (実売 1,955 個・$145k、単価 $74)。**品目別の約定個数と単価を出せる計装が先**。
   数値は `refs/top-survey-2026-09-18.md`。
6. **1 位は我々と同じ v46 シャシー** (農場行動は step 24 まで完全一致)。486 点差は全部ライブ層にある。
