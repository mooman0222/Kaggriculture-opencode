## 3. 測り方

| 目的 | コマンド |
|---|---|
| 自分の土台に対する上乗せ | `tests/kag_eval.py agents/X/main.py --vs third_party/public_agents/<土台>/main.py --games 32` |
| 現提出との比較 | `--vs agents/<現提出>/main.py --games 32` |
| **実戦席差し替え (最も当てになる)** | `--replays 'tmp/<battles>/episode-*.json' --team MMN0222 --base agents/<現提出>/main.py` |
| 世界を固定 | `--shops <8 店をカンマ区切り>` |
| 実戦の取得 | `kaggle competitions episodes <ref>` → `xargs kaggle competitions replay` → `tests/fetch_battles.py` / `tests/rating_traj.py <ref>` |

- **ユニット行動を触らない層なら分散が小さく微差が測れる** (クローンが保たれるため)。触ると位置がドリフトして分散が跳ねる。
- **同 seed・同席のペア差**を取る (`scratchpad/ab_dawn.py` の形)。夜明けガードは +248±24 (t=10.3) で検出できた。
- **調整用と判定用の seed を分ける**。tune 7000-7059 / held-out 8000-8059 で値が一致すれば過適合なし。
- **seed 範囲で結果が変わる**: 同じ E066 vs v46 が seed 0-15 で +102、seed 7000-7039 で +366。狭い範囲で結論を出さない。

## 6. 生きている問い

1. **自前の層を持つ相手に勝てない**。実戦 120 戦の分解: v43 型開幕の相手 61 局 67%/+1,028、**v46 素 31 局 58%/+399**、
   **v46 + 自前の層 23 局 22%/−1,710**。唯一の負け筋がここ。相手の層は (a) 売りの**時刻を組み替える** (同じ品目を消しては足す)、
   (b) **h0-2 と h21-23** に集中、(c) 76% でスロット 0 に SELL、(d) ユニット行動も 16.3% の step で変える。
   夜明けガードは (b) の入口を押さえたが、(a)(d) は未着手。
2. **エンジン規則の残りの穴を探す**。`refs/engine_facts.md` と `third_party/kaggriculture-cppsim/sim/sim.hpp` を突き合わせる。
   夜明けガードは `drop_inventories` から見つけた。同種の規則がまだあるはず。
   **探す目のあたり (09-18 の測定)**: 得点は行動ノイズに対し `own ≈ 63,072 × (1−ε)^10` で落ちる。
   **実効の鎖長 k ≈ 10** — 植える→水→収穫→拾う→運ぶ→売る のどれか 1 本が切れると後ろが全部無効になる。
   **切れた鎖を繋ぎ直す層は効きが大きい**、が夜明けガード (+250) と給餌ガード (+30) の正体。
   次は「どこで鎖が切れているか」を数えること (破棄・未給餌は塞いだ。残るのは未散水・持ち帰り忘れ・運搬の空振り)。
   測り方は `experiments.md` の 4d 行、ノブは `play2.py --eps / --eps-op`。

   レーティングは 600 から 2,114 へ上昇中 (収束前。壊れてはいない)。
