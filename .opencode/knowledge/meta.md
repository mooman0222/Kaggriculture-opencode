# Meta (コンペ状況・メタ情報)

## スコアリング (評価ページより)

- **Elo 式スキルレーティング**。勝ちで上昇・負けで下降・引き分けは互いに接近
- レーティング変動は勝敗のみ。**コイン差は無関係**
- 新規提出は初期レーティング 600 でマッチメイキングに参加
- レーティングの近い相手と継続的にマッチングされる
- 最終順位は提出期限後に ~2週間の追加試合を経て **Bradley-Terry トーナメント**で決定

## レーティングの動き方 (前回1位 Ryo Hasegawa の記事 736219 より、本文は refs/discussion-736219-rating.txt)

- 更新係数は K ≈ 200·e^(−n/26)。**最初の ~60 試合で約90%収束** (最初は ~15試合/時、その後 1〜2試合/時)
- 収束曲線は μ(n) ≈ a + b·ln(n)。a は最初の ~40 対戦相手の引き運 (±130 程度、コピー提出でも結果が大きくばらつく)
- 残差ノイズは ±25〜50 ポイント。**50ポイント未満の差はノイズ**とみなす
- **提出の判断基準**: 60試合 (~5時間) 経過前に判断しない。同一試合数で比較する
  (新規 50試合と既収束 300試合の比較は無意味 — 古い方が 100〜150 有利に見える)
- **再提出戦略**: 2スロット制 (最新2つのみ有効)。未変更ボットの再提出は無意味 (最終ランキングに影響しない)。
  スロット1は最強ボットを据え置き、スロット2は「本当に強いと確信した版」か「メタ変動へのヘッジ」のみ
- **最終評価**: 期限後の ~2週間の試合で Bradley-Terry を再計算。期限日にスロットにある
  2つが最終評価対象。未テストコードを期限日に出さない (エラーで試合に出られないと何も得られない)
- **オフライン最適化**: 平均コインではなく**周辺レーティングの相手に対する勝率**を最適化する。
  同じシードで変種を比較し、強い相手ごとの勝率で判断する (プール平均に埋もれさせない)

## 実測によるスコアリングの観察 (2026-08-29、ref 55861715 の28試合から)

- **新規提出は毎回 600 からスタート**: 55861715 は 7試合で 750.7 → 28試合で 687.9 (直近13試合は
  5勝8敗 = 38%)。**提出し直すたびに積み上げたレーティングが破棄される** — 頻繁な再提出は停滞の一因
- 勝敗のみでレーティングが動く (コイン差は無関係)。$245 差の敗戦も $27k 差の敗戦も同じ -K 点
- 4分間隔で試合が進む (~15試合/時) → 60試合 ≈ 4時間強で収束
- 実戦の勝率 (38%) が vs base の優位 ($96k) と乖離する主因 (E018 分析):
  **ショップ抽選 (羊毛)**: YARN_STORE が引けないゲームでは羊毛が $1 に暴落し
  ±$15-20k のスイング (vs base でも同様の抽選があり、シード間の分散の主因)
