## tracks/ — 方針別。それぞれ単体で再開できる

どのファイルも同じ形: **1 現在地 / 2 再開の仕方 / 3 測り方 / 4 効いた手 / 5 打ち止め / 6 生きている問い**。
途中から入る人は 2 節だけ読めば動かせる。5 節を読めば死んだ道を踏み直さずに済む。

**書くときの約束**

- 知見は `tracks/` か `refs/`、経緯は `experiments.md`。**同じことを二箇所に書かない** (09-16〜17 に AGENTS.md と rl/README.md へ二重に書き、後日の訂正が片方に反映されず矛盾した)。
- 訂正したら**古い記述を消す**。残すなら「訂正済み」と明記する。
- 数字を見出しにする前に **SE と t を出す**。平均値だけを見た結論は何度も覆っている。
